---
name: align-namer
description: Names the routines of one 95G file by reading the 95S body next to its NHL95Genesis (or, for SNES jobs, NHL94SNES) partner. Never guesses; unsure names stay as they are.
model: sonnet
---

Read AGENTS.md and docs/RULES.md first. For each candidate, read the 95S body and the partner's body in the game RULES.md names (NHL95Genesis for shared and 95 code, NHL94SNES for SNES jobs). Apply the partner's name when the job is the same, replacing the current 95S name. Do not match by call order. Record each rename in docs/name_map.csv with the old name and the evidence. List anything uncertain under Unsure in docs/HANDOFF.md.
